\# Prompt Engineering Lab - Connectivity Test (Ollama)



\## Description

Python script that connects to a local LLM using \*\*Ollama\*\* and tests basic prompt engineering connectivity.  

No paid API key is required.



\## Requirements

\- Python 3.8 or higher

\- Ollama installed and running

\- A local model pulled (example: `llama3.2`)



\## Setup



\### 1. Install Ollama

Download from: https://ollama.com/download



\### 2. Pull a model

```bash

ollama pull llama3.2
